第3条取得する情報と取得方法

運営者は、本サービスにおいて、次の情報を取得します。

  1. ユーザーが入力・提供する情報
    1. しおりやスポットに関する情報（タイトル、日程、場所の名称・住所・位置、時間、メモなど、ユーザーが入力・保存した情報）
    2. 会員登録に関する情報（メールアドレス、Apple IDで登録した場合にAppleから提供される識別子・メールアドレスなど）。なお、パスワードは認証サービスが管理し、運営者のサーバーには保存されません。
    3. お問い合わせの内容およびメールアドレス（お問い合わせフォームに入力された情報）。なお、お問い合わせフォームには、運営者から求めた場合を除き、メールアドレス以外の個人情報（パスワード、住所など）を入力しないでください。
  2. アカウントに関する情報
    アカウントを識別するための識別子（認証サービスが発行するユーザーID）、認証方式、アカウントの作成・更新日時などを取得します。匿名アカウントでも、識別子は発行されます。
  3. アクセス・端末に関する情報（本サービスの利用に伴い自動的に取得する情報）
    IPアドレス、アクセス日時、リクエストの内容、アプリのバージョン、端末・OSに関する情報などを、運営者のサーバーが取得します。
  4. エラー情報
    本アプリで不具合やクラッシュが発生した場合に、エラーの内容、発生箇所、端末・OS・アプリのバージョン、発生日時、発生前後の操作や通信の記録、匿名の識別子、IPアドレスなど、原因の調査に必要な情報が、エラー監視サービスに送信されることがあります。
  5. 位置情報（現在地）
    ユーザーが端末の設定で許可した場合に限り、端末の現在地を取得します。現在地は、地図の表示などのために端末内でのみ利用し、運営者のサーバーに送信・保存することはありません。なお、ユーザーがスポットとして保存した場所の位置情報は、スポットに関する情報として保存されます。
  6. 場所の検索に関する情報
    場所の検索や地図上の地点の指定を行う際に入力・指定された検索キーワードや地点の緯度経度は、Appleが提供する機能に送信され、Appleにより処理されます。運営者は、検索キーワードを取得・保存しません。
  7. 自由記載欄の内容
    メモなどの自由記載欄に入力された内容（病歴、信条など、個人情報保護法上の要配慮個人情報に当たりうる内容を含みます。）は、ユーザー自身の判断で入力されるものであり、運営者がこれらの情報の入力を求めるものではありません。ユーザーは、要配慮個人情報その他の重要な情報を入力しないでください。

第4条利用目的

  1. 運営者は、利用者情報を次の目的で利用します。
    1. 本サービスの提供（認証、データの保存・表示・復元など）
    2. 不正利用・不正アクセスの防止、セキュリティの確保
    3. 不具合の調査・修正、本サービスの品質向上および機能の改善、アプリのバージョンの確認
    4. お問い合わせおよび第9条の請求への対応（本人確認を含みます。）
    5. 利用規約その他の規約に違反する行為への対応
    6. 利用規約・本ポリシーの変更、サービスの停止・終了その他の重要なお知らせの通知
    7. 個人を特定できない形に加工した統計情報の作成
  2. 運営者は、利用目的を、変更前の利用目的と関連性を有すると合理的に認められる範囲を超えて変更しません。利用目的を変更した場合は、変更後の目的を本アプリ上または本ポリシーを掲載するウェブページで公表します。
  3. 運営者は、法令に基づく場合その他法令で認められる場合を除き、ユーザーの同意なく、あらかじめ特定した利用目的の達成に必要な範囲を超えて個人情報を取り扱いません。

第5条第三者提供

  1. 運営者は、次の場合を除き、あらかじめユーザーの同意を得ることなく、個人データを第三者に提供しません。
    1. ユーザーの同意がある場合
    2. 法令に基づく場合
    3. 人の生命、身体または財産の保護のために必要がある場合であって、ユーザーの同意を得ることが困難であるとき
    4. 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、ユーザーの同意を得ることが困難であるとき
    5. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、ユーザーの同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき
    6. 事業の譲渡その他の事由による事業の承継に伴って個人データが提供される場合（利用規約に定めるとおりです。）
    7. 利用目的の達成に必要な範囲で、個人データの取扱いの全部または一部を委託する場合（次条に定めるとおりです。）
  2. 運営者は、個人データを第三者と共同利用しません。

第7条保存期間と削除

  1. アカウントに関する情報およびユーザーデータは、アカウントが存続する間、保存します。
  2. ユーザーが、匿名アカウント・登録アカウントを問わず、本アプリ内の削除機能からアカウントを削除した場合、運営者のサーバー上のアカウントに関する情報およびユーザーデータは削除され、認証サービス上の認証情報も削除されます。バックアップ等からの完全な削除には、一定の期間を要する場合があります。また、通信障害その他の事情により、削除が直ちに完了しない場合があります。
  3. 利用規約に定めるとおり、ユーザーが既存のアカウントへの切り替えを選択した場合、切り替え前の匿名アカウントとそのユーザーデータは、運営者により削除されることがあります。
  4. アクセスログおよびエラー情報は、第4条の利用目的の達成に必要な期間保存し、その後、削除し、または個人を特定できない形にします。
  5. お問い合わせの内容およびメールアドレスは、運営者がアクセスを管理するGoogleアカウント上で保管し、対応や改善に必要な期間が経過した後、削除し、または個人を特定できない形にします。
  6. 前各項にかかわらず、法令に基づく保存義務や、紛争への対応その他正当な事由がある場合は、必要な範囲で一定の情報を保持することがあります。

第8条安全管理措置

  1. 運営者は、個人データの漏えい、滅失または毀損の防止その他の安全管理のために、通信の暗号化、アクセス制御、不正アクセスへの対策、秘密情報の管理、委託先の監督など、本サービスの規模および性質に応じた必要かつ適切な措置を講じています。
  2. 個人データの漏えい等が発生し、個人情報保護法に基づく報告または通知が必要な場合は、同法に従い、個人情報保護委員会への報告およびユーザーへの通知を行います。
  3. 運営者は、以上の措置を講じていますが、情報の絶対的な安全性を保証するものではありません（利用規約第18条をご参照ください。）。

第9条ユーザーの権利と請求手続

  1. ユーザーは、運営者が保有する自身の保有個人データについて、個人情報保護法に基づき、次の請求をすることができます。
    1. 利用目的の通知
    2. 開示（電磁的記録による提供を含みます。）
    3. 内容の訂正、追加または削除
    4. 利用の停止または消去
    5. 第三者への提供の停止
    6. 第三者提供記録の開示
  2. 前項の請求は、第14条のお問い合わせフォームから申し出てください。運営者は、フォームに入力されたメールアドレス宛に返信し、必要に応じて追加の確認事項をお尋ねします。運営者は、ご本人であることおよび対象となるアカウントを確認したうえで、遅滞なく対応します。特に匿名アカウントについては、対象のアカウントを特定できる情報をご提示いただく必要があり、特定できない場合は、対応できないことがあります。
  3. 請求への対応に、現時点で手数料はかかりません。請求に応じない場合は、その旨をユーザーに通知し、理由の説明に努めます。
  4. アカウントとユーザーデータの削除は、本アプリ内の削除機能から、いつでも行うことができます（利用規約をご参照ください。）。
  5. 次のいずれかに該当する場合は、請求に応じないことがあります。
    1. ご本人であることまたは対象のアカウントを確認できない場合
    2. ユーザーまたは第三者の生命、身体、財産その他の権利利益を害するおそれがある場合
    3. 運営者の業務の適正な実施に著しい支障を及ぼすおそれがある場合（正当な理由なく繰り返される請求や、バックアップデータ内のデータの個別削除など過度な技術的負担を要する請求を含みます。）
    4. その他、法令により運営者が義務を負わない場合または法令に違反することとなる場合

第10条位置情報の許可と情報提供の任意性

  1. 位置情報（現在地）の利用は、端末の設定からいつでも変更できます。許可しない場合でも、現在地を使う機能以外の機能は利用できます。
  2. ユーザーは、会員登録を行わず、匿名アカウントで本サービスを利用できます。ただし、匿名アカウントのデータは、利用規約に定めるとおり、アプリの削除や端末の変更等により復元できなくなります。
  3. 個人情報の提供を希望されない場合は、アカウントを削除したうえで、本アプリの利用を中止してください。

第11条子どもの情報

  1. 13歳未満の方は、本サービスを利用できません。運営者は、13歳未満の方の個人情報を取得したことが判明した場合、速やかに削除します。
  2. 未成年のユーザーは、利用規約に定めるとおり、親権者その他の法定代理人の同意を得たうえで本サービスを利用してください。

  3. 法令上ユーザーの同意が必要となる変更を行う場合は、運営者が定める方法により、同意を取得します。
